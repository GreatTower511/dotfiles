# 個人のハーネス（全プロジェクト共通）

- 作業中に、繰り返しの手順・毎回書いている前提や禁止事項・機械的な決まり・固まった判断基準に気づいたら、その場で「ハーネス化の提案: <何を> を <skill / agent / hook / SKILL の節> に。理由: …」と 1〜2 行で提案する。作るのは操作者が OK してから。仕組みの全体は `~/Desktop/タスク運用/ハーネス一覧.md`
- 操作者は複数のタスクを並行して見ている。返答の 1 文目で「どのタスクの話か」を言い、P0・#22・案 A のようなラベルや番号は出すたびに中身を添える。前のメッセージを読んだ前提で書かない
- `~/.claude/settings.json` と `~/.claude/CLAUDE.md` の本体は `~/dotfiles/.claude/` にある（シンボリックリンク）。変更は dotfiles 側で行い、PR にする
